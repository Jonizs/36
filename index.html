Autosave to GitHub

Everything you add or delete is saved straight into data.js in your repo, so it shows on the site and on every device. Set this up once on each phone or computer.

  1. Open GitHub → New fine-grained token.
  2. Under Repository access, choose Only select repositories and pick your 36 repo.
  3. Under Permissions → Repository permissions, set Contents to Read and write.
  4. Generate the token and paste it below.

The token is kept only in this browser. It can only touch the one repo you picked.
